# Tells: what makes slides look generated or templated

Adapted from Taste Skill's dated `tells.md` for slides. A tell is a device produced by default,
without a reason. Rows marked **brand** are allowed when the user's theme uses them (SKILL.md §0); the
rule then is "with a job, not everywhere".

| Tell | Do instead |
|---|---|
| Title + bullet list on every slide | One claim per slide; vary layouts (split, statement, big number, picture, diagram) |
| Generic titles: Introduction, Overview, Background, Conclusion, Thank you, Q&A as a whole slide | Assertion titles; a closing slide that restates the one takeaway and the ask |
| Three identical cards, each with an icon in a rounded square | A real diagram, a comparison, or one strong example; library components where they explain |
| Icon on every bullet | Icons only where they carry meaning (a law icon on the legal point) |
| Purple-to-blue or rainbow gradients, gradient text | The theme's flat colours |
| Soft drop shadow under every box | Tone steps or space; a shadow only on the one thing floating over a photo |
| Everything centred | Left-anchored; one centred moment |
| Many near-equal font sizes; 3+ font families | 3 sizes per slide, 5 per deck; the theme's pairing |
| Glass panels everywhere (**brand** allows them on photo slides) | One glass panel over a photo, not a glass UI |
| Tiny tracked uppercase labels on every slide (**brand** allows kickers) | One kicker style, same place, only where it orients (section name) |
| 01 / 02 / 03 numbering (**brand** allows it in Index / Heritage / Slate) | Only when the order is real information (steps, chapters) |
| Stock photos: handshakes, lightbulbs, people pointing at screens, blue "blockchain" network globes | The real thing (the Hive, the MRT, a real block explorer screenshot), a library component, or type alone |
| AI images with garbled letters or extra fingers | Regenerate, crop it out, or drop it |
| Clip-art, WordArt, emoji as bullets | Words, real pictures, library icons |
| Every element animated with the same fade | Animate only what reveals the argument (a step appearing, a number counting) |
| A loud motion style on several slides | One per deck, on a cover, divider or closing |
| Decorative "data" (fake dashboards, random charts) | Real numbers with a source, or no chart |
| Template leftovers: "Click to add title", Lorem, a LOGO box, demo numbers | Remove or replace with real content before hand-over |
| A wall of text at 12pt "so it fits" | Split the slide, move detail to speaker notes |
| Agenda slide listing 8 generic sections | A 3–5 step path in the deck's own words, or no agenda |

**Removal is not enough.** A deck with every tell removed and nothing in its place is an empty deck
with good manners. The tells were filling the gap where the idea should be: fill it first (SKILL.md
§1 step 2), then check this list.
