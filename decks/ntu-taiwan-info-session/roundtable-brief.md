# 圓桌論壇準備（2026-11-06 場次）

論壇在學生分享之後（20:05–20:35），三個議題。以下分成「可以放心講」、
「不要講」、「你的獨特角度」。資料查於 2026-11-05。

## 立場先定調

台上另外幾位是業界講者與主持人，你是**在學學生**。你的價值不是比他們懂產業，
而是「正在念這個系、正在找路的人」的第一手視角。產業數字講錯比說「我不知道」傷更大。
遇到不確定的，把球丟回去：「這個我還在學，想請教○○總的看法。」

## 議題一　區塊鏈在產業落地時，哪些問題值得投入？哪些導入障礙仍未解決？

**可以放心講的（業界共識，不會被打臉）**
1. **現金端（cash leg）**：資產上鏈了，錢還在鏈下，DvP（款券同步交割）做不成。
   這是穩定幣與 CBDC 想解的核心問題。
2. **互通性**：各公鏈、各聯盟鏈不互通，資本效率與市場深度上不去。
   新加坡 Global Layer One 做的就是這件事。
3. **法律效力與最終性**：鏈上轉讓在法律上算不算交割完成，各國認定不一。
4. **隱私與可稽核的矛盾**：機構不可能把部位全公開，但監理又要看得到。
5. **次級市場流動性薄**：代幣化資產發得出來，但買賣不熱絡。
6. **與既有系統整合的成本**：銀行的核心系統不是為了上鏈設計的。

值得投入的方向：資產代幣化（國債基金、私募信貸目前量最大）、跨境支付與結算、
法遵與監理科技、機構託管。

**不要講**
- **不要報市場規模的精確數字。** 各家追蹤器算法不同，2026 年秋的「鏈上代幣化資產」
  從 220 億到 510 億美元都有人講，私募信貸的占比差距更大。真要提就說
  「數百億美元等級、國債基金和私募信貸占大宗」，別講到小數點。
- 不要預測時程（「三年內會如何」）。
- 不要評斷哪個專案會成功。

## 議題二　企業招募時看重哪些基礎、作品與經驗？

**這題你最有底氣**，因為你手上有一份今年 Q3 的調查（MoleDAO，152 家 Web3 公司、
1,104 筆職缺）。引用時講明出處，沒人能說你亂講。

- **技術棧是通用的，不是鏈上的**：Python 出現在 32% 的工程職缺，其次是 Go、AWS、
  SQL、Kubernetes、Java。**Solidity 和智能合約很少被明確要求。**
- **AI 技能比鏈上技能更常被提到**：LLM 和 AI agent 各約 13% 的工程職缺。
- **產業經驗沒有想像中必要**：只有 34.2% 的職缺明確要求有 crypto／區塊鏈經驗，
  另外 8.2% 列為加分 → 將近六成不要求。
- **依職能差很多**：工程只有 28.7% 要求產業經驗，業務／BD 高達 54.1%，
  產品與合規約 40%。
- **依公司類型也差很多**：交易所最寬鬆（約 30%），公鏈與基礎設施最嚴（62.8%）。
- **合規是缺口最大的**：占職缺 7.5%，只收到 2.3% 的應徵。

作品的部分報告沒有數據，想講就講自己的觀察，**不要說成是調查結果**。

## 議題三　應屆生、工程師、跨領域人士如何準備？

- **應屆生**：這份調查裡，實習與 entry-level 加起來只占約 14%，報告原文說
  「實習是進入頭部公司唯一實際的入口」。先求實習，不要硬投全職。
- **有 1–2 年經驗的**：80 個 entry-level 職缺裡只有 8 個職稱寫明 junior，
  其餘 72 個職稱是 Analyst／Associate／Specialist，但 JD 只要求兩年以下經驗。
  集中在營運、工程、合規，由 Binance、Coinbase、Crypto.com 發布，**不少在港星台**。
  → 實戰建議：不要被職稱嚇跑，逐行讀 JD 的年資要求。
- **工程師轉入**：技術棧與一般網路業高度重疊，不需要深度鏈上開發經驗。
  各家有偏好（Kraken 偏 Rust、OKX 偏 Java、Coinbase 偏 Go），投遞前先對一下。
- **跨領域／文組**：合規、風控、AML 是供需缺口最大的一塊。台灣的分析建議補
  CAMS、CRCM 這類國際證照。
- **語言**：1,104 筆職缺中有 60 筆明確要求中文，主要在香港、新加坡、台灣。
  對台灣學生，中文是實質加分。

# 企業招募這題，展開版（2026-11-05 補）

## 先處理一個會被打臉的矛盾：Solidity

MoleDAO 報告說「Solidity、智能合約很少被明確要求」。但我往外查，
web3.career、crypto.jobs 這類職缺板說「Solidity 出現在 40% 以上的開發職缺，
Rust 約 25%」。**兩邊差很多，你在台上講錯邊會被業界講者當場糾正。**

兩邊其實都對，差在取樣：

| | MoleDAO | 職缺板 |
|---|---|---|
| 樣本 | 152 家 Web3 原生公司的**官方 ATS**，交易所占 45% 的職缺 | 公開職缺板，大量公鏈／DeFi／新創 |
| 誰在招 | Binance、Coinbase、Kraken 這類**像金融科技公司**的雇主 | 協議團隊、智能合約團隊 |
| 要的人 | 後端、資料、雲端、交易系統 | 智能合約、協議開發 |

MoleDAO 自己的數字也印證：公鏈與基礎設施是 48 家公司、只發了 113 個職缺，
而且對產業經驗要求最嚴（62.8%）。

**安全講法**：不要說「Solidity 不重要」。要說
「**看你要去哪一種公司。** 交易所、支付、託管這類要的是後端和資料工程師，
技術棧跟一般網路業重疊；公鏈和 DeFi 協議才是 Solidity、Rust 的主場，
但那邊職缺少、而且最要求產業經驗。」
這個答案更站得住腳，也顯得你讀過不只一份資料。

## 工程（職缺 27.2%／應徵 22.4%）

- Python 出現在 **32%** 的工程職缺，其次 Go、AWS、SQL、Kubernetes、Java
- LLM 與 AI agent 各約 **13%**，比鏈上技能更常被提到
- 工程職只有 **28.7%** 要求產業經驗，是所有職能裡第二低
- 各家有偏好：Kraken 偏 Rust、OKX 偏 Java、Coinbase 偏 Go
- 但工程的 entry-level 只占 **8.2%** — 要的是有經驗的人
- 薪資最高：平均底薪 211K 美元（樣本以美國為主，亞太低於 100K）

一句話：**「這個產業要的工程師，跟一般網路業要的是同一種人。門檻不在鏈上知識，在後端和資料。」**

## 合規・法務・風控（職缺 7.5%／應徵 2.3%）

- 職缺是應徵的 **3.3 倍**，報告原文稱為「classic blue ocean」「現在 CP 值最高的一條路」
- Kraken 第三季的新職缺從工程轉向合規：英國的 AML 主管、法遵律師、市場監控
- **不只交易所在招**：賣合規工具的 TRM Labs、Chainalysis，支付託管的 Ripple、Fireblocks
  也同步在招工程師、分析師和業務
- Bybit 有 **31.3%** 的職缺是合規與風控，六大交易所裡最高
- 合規職約 40% 要求產業經驗（中等）
- 薪資 162–164K 美元帶，低於工程
- 外部資料：最常被點名的證照是 **CAMS**；工具是 Chainalysis、Elliptic；
  法規知識是 FATF Travel Rule、歐盟 MiCA。**Python 和 SQL 在合規職也被列為加分**

一句話：**「缺口不是沒有職缺，是沒有人去投。而且不只交易所在招，賣合規工具的公司也在招。」**

## 行銷・成長（職缺 7.9%／應徵 20.8%）

- 應徵占比是職缺占比的 **2.6 倍**，報告說是「目前競爭最激烈的領域」
- **行銷的 entry-level 只占 2.9%，是所有職能裡最低的**
  （對照：資料與 AI 36.4%、營運 18.2%、工程 8.2%）
- 報告建議：靠具體的專案成果和人脈做出區隔，不要海投

一句話：**「最多人想做，但新鮮人職缺最少。2.9%，所有職能裡墊底。」**

## 把三項串起來的一個觀點（你自己的，不是報告的）

報告說合規缺人，也說合規職位看重 Python 和 SQL；
而 Python 出現在 32% 的工程職缺。這兩件事交集起來：

**最稀缺的不是工程師，也不是純法遵，是「看得懂鏈上資料的法遵」。**

這正好解釋你為什麼選 SC6124（區塊鏈倫理與法律）和 SC6125（區塊鏈與金融）：
技術底在必修打完，選修補法律和金融，就是往那個交集走。

這是你的推論，**不要說成是報告的結論**。講法：「我自己的讀法是……」
