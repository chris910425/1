# NTU 台灣招生說明會：學生代表分享

## 基本資訊
- **場合：** NTU CCTF 赴台招生說明會，以學生代表身分分享就讀體驗與心得
- **聽眾：** 考慮申請 NTU 的台灣學生（可能也有家長）
- **講者：** NTU MSBT（區塊鏈）碩士生，台灣人
- **長度：** 5 分鐘
- **語言：** 繁體中文，台灣用語
- **形式：** HTML 簡報
- **主題風格：** 融入 NTU CCTF 老師們平常用的簡報風格（參考 `inspiration/ntu-cctf/capstone-briefing-cover.webp`）
  - 必須保留：配色（深藍漸層＋NTU 紅色點綴、白字）與校徽 logo
  - 版面不必完全照抄
  - 使用者正在自己做模板，**等模板完成再討論怎麼套內容**，在那之前不做投影片
- **CCTF：** NTU Centre in Computational Technologies for Finance（Graduate College）

## 設計方向（2026-10-21 討論中）
- **模板：** Raw Grid（`templates/rawgrid/`，PowerPoint 版，PPT Master brand `raw-grid`）
- **字體：** Noto Sans TC
- **封面構想：** 參考 `cover-reference.png`（灰階仰拍大樓、置中標題、橫貫全版細線、外框按鈕、底部橘色方塊箭頭），背景換成 The Hive
- **配色：** 以 CCTF 深藍漸層＋NTU 紅為主，依 Raw Grid 的配色邏輯延伸（CCTF 封面實測：#161F62、#122B73、#0B3783、#0C4994、淺藍 #CBE0EC、紅 #D21540）
  - 提議對應：線條／文字／硬陰影 → 深藍 #161F62；粉色格 → NTU 紅淺色；綠色格 → 淺藍；強調色（每頁一處）→ NTU 紅 #D21540；黑色區塊（takeaway、terminal）→ 深藍漸層
- **甜甜圈圖：** 不用模板內建的，改照 HTML 元件庫 `doughnut` 的樣式重做：細圓環、扇形間留小縫、中間大數字＋小標、右側圖例列（色塊＋名稱＋右對齊數值）、只有重點扇形用強調色，其他用主色深淺
- **Claude 的判斷（封面融合）：** 兩種風格語言不同（照片＋細線置中 vs 平面白底＋粗線格子），直接拼會像兩份簡報。融合方法：照片調成深藍雙色調、細線改成 Raw Grid 的 3px 線（照片上用白線）、標題用 Noto Sans TC Black、外框按鈕與底部方塊改成 Raw Grid 的格子＋硬陰影、校徽放在白色格子裡；結尾頁用同一張照片首尾呼應
- **元件建議：** 開場→分欄＋箭頭列；為什麼 NTU→大數字格或圖示格；生活開銷→甜甜圈＋底部 takeaway 列；住宿→五步驟欄（目前步驟標紅）＋手繪圈重點字；兩個主軸前各一頁章節頁；課程→區塊鏈（課程＝區塊）＋「18:30–21:45」大數字＋螢光筆效果；實習→圖示格或箭頭列；聯絡→結尾頁版型
- **待確認：** 輸出格式（PPTX 或 HTML）；NTU／CCTF 官方 logo 檔；是否加兩頁章節頁；封面選 A 或 B；標題文案；講者姓名與場次日期

### Claude 的檢討
- 兩版共同：紅色 ↓ 方塊在投影片上沒有功能（來自參考圖的網頁捲動提示），建議刪掉，或改成整份簡報重複出現的頁碼／章節標記
- A：置中元素有四層（標題／副標／事件框／箭頭），偏網頁首頁感；副標的淡藍字壓在樹叢上對比不足；左下講者資訊離邊太近且壓在塔身細節上
- B：右欄下半大片空白；白色格子的硬陰影在深藍照片上幾乎看不見
- 建議：以 B 的結構為底，把標題放大、事件格移到左欄標題下方，右欄留給照片呼吸

### 字體與設定的連帶影響（待使用者決定）
1. **Latin 字體**：Raw Grid 原設定是 Segoe UI Black（英數）＋Noto Sans TC Black（中文）。封面測試稿改成**全部用 Noto Sans TC Black**
   - 理由：這份簡報中英混排很多（NTU、MSBT、CCTF、S$1,850），同一套字重高度一致；且不依賴只有 Windows 有的 Segoe UI
   - 若要改回 Segoe UI Black，只影響英數字，中文不變
2. **顏色（必須整份跟著改）**：Raw Grid 的黑 #0A0A0A → 深藍 #0A1138；粉色格 → NTU 紅淺色；綠色格 → CCTF 淺藍 #CBE0EC；強調色 → NTU 紅 #D21540。封面是深藍，內頁若維持黑線會脫節
3. **深／淺節奏**：封面深、內頁白、章節頁深藍（可放淡化的 Hive 當底紋）→ 首尾與分段呼應
4. **照片統一**：整份簡報所有照片都要用同一套深藍雙色調
5. **線條語言**：深底用白色 3px 線，白底用深藍 3px 線，是同一套格線的正負片
