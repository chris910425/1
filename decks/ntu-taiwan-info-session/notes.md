# NTU 台灣招生說明會：學生代表分享

## 基本資訊
- **場合：** NTU CCTF 赴台招生說明會，以學生代表身分分享就讀體驗與心得
- **聽眾：** 考慮申請 NTU 的台灣學生（可能也有家長）
- **講者：** NTU MSBT（區塊鏈）碩士生，台灣人
- **長度：** 5 分鐘
- **語言：** 繁體中文，台灣用語
- **形式：** HTML 簡報
- **主題風格：** 融入 NTU CCTF 老師們平常用的簡報風格（參考 `inspiration/ntu-cctf/capstone-briefing-cover.webp`）
  - 必須保留：配色（深藍漸層＋NTU 紅色點綴、白字）與校徽 logo
  - 版面不必完全照抄
  - 使用者正在自己做模板，**等模板完成再討論怎麼套內容**，在那之前不做投影片
- **CCTF：** NTU Centre in Computational Technologies for Finance（Graduate College）

## 設計方向（2026-10-21 討論中）
- **模板：** Raw Grid（`templates/rawgrid/`，PowerPoint 版，PPT Master brand `raw-grid`）
- **字體：** Noto Sans TC
- **封面構想：** 參考 `cover-reference.png`（灰階仰拍大樓、置中標題、橫貫全版細線、外框按鈕、底部橘色方塊箭頭），背景換成 The Hive
- **配色：** 以 CCTF 深藍漸層＋NTU 紅為主，依 Raw Grid 的配色邏輯延伸（CCTF 封面實測：#161F62、#122B73、#0B3783、#0C4994、淺藍 #CBE0EC、紅 #D21540）
  - 提議對應：線條／文字／硬陰影 → 深藍 #161F62；粉色格 → NTU 紅淺色；綠色格 → 淺藍；強調色（每頁一處）→ NTU 紅 #D21540；黑色區塊（takeaway、terminal）→ 深藍漸層
- **甜甜圈圖：** 不用模板內建的，改照 HTML 元件庫 `doughnut` 的樣式重做：細圓環、扇形間留小縫、中間大數字＋小標、右側圖例列（色塊＋名稱＋右對齊數值）、只有重點扇形用強調色，其他用主色深淺
- **Claude 的判斷（封面融合）：** 兩種風格語言不同（照片＋細線置中 vs 平面白底＋粗線格子），直接拼會像兩份簡報。融合方法：照片調成深藍雙色調、細線改成 Raw Grid 的 3px 線（照片上用白線）、標題用 Noto Sans TC Black、外框按鈕與底部方塊改成 Raw Grid 的格子＋硬陰影、校徽放在白色格子裡；結尾頁用同一張照片首尾呼應
- **元件建議：** 開場→分欄＋箭頭列；為什麼 NTU→大數字格或圖示格；生活開銷→甜甜圈＋底部 takeaway 列；住宿→五步驟欄（目前步驟標紅）＋手繪圈重點字；兩個主軸前各一頁章節頁；課程→區塊鏈（課程＝區塊）＋「18:30–21:45」大數字＋螢光筆效果；實習→圖示格或箭頭列；聯絡→結尾頁版型

## 設計規則（使用者 2026-10-23 確認，不可違反）
1. **白色是主背景色**，跟 Raw Grid 模板一樣。深藍 `#0A1138` 只是取代 Raw Grid 原本的黑色，用在線條、文字、硬陰影，**不是底色**。
2. **深藍不能變成主角。** 不做深藍滿版底的投影片。章節頁也用白底。
3. **照片保持原本的顏色**，不做深藍雙色調（先前的雙色調版本已刪除）。
4. 封面是唯一的照片頁，照片夾在上下兩條白色帶之間。
5. 版面採**版本 B 的 Raw Grid 格線結構**（使用者選定）。
6. NTU 紅 `#D21540` 是強調色，每頁只用一處；CCTF 淺藍 `#CBE0EC` 取代 Raw Grid 的綠色，當安靜的填色。

### 各頁內容細節

**2. 為什麼是新加坡**（使用者決定只講新加坡，不講 NTU）
- 01 在國際級職場裡學：近年成為亞洲金融中心，許多跨國企業把亞洲總部設在這裡
- 02 生活安全、乾淨：治安好、公共環境整潔
- 03 離家 4.5 小時：直飛台北
- 元件庫有真實新加坡輪廓（`geo.js`，Natural Earth 公眾領域）與 `flight`（台北→新加坡航線＋距離）

**5. 產業在缺什麼人**
- 來源一：MoleDAO 2026 Web3 就業調查（LinkedIn）→ 產業現在缺什麼樣的人
- 來源二：Tokenization，傳統金融機構即將整合區塊鏈 → 可往 Finance / FinTech 發展，這兩項在新加坡是熱門高薪行業
- 官方場合建議在頁面底部放出處行

**6. 能學到什麼、怎麼選課**（課程取自官方大綱）
- 必修 9 門打底：區塊鏈技術 1&2、分散式系統、密碼學、軟體工程、區塊鏈開發 1&2、智能合約安全、隱私與擴容
- 選修・開發 6 門：Web 程式、智能合約方案、dApp 開發、軟體專案管理、資安、賽局理論
- 選修・管理與金融 5 門：代幣經濟、FinTech 新趨勢、區塊鏈商業應用、**區塊鏈倫理與法律 SC6124**、**區塊鏈與金融 SC6125**
- 專題：SC6131 Blockchain Innovation Project，3–6 個月，業界專家共同指導
- 講者論點：市場缺合規人才，也缺「懂金融又能跟工程師溝通」的人（MoleDAO 可佐證）→ 所以會選法律與金融相關課程
- 行動呼籲：先去官網看完整大綱，想清楚要把自己變成什麼人，再回來選課

**7. 晚上上課，白天實習**
- 課程多在晚上（**待確認 18:00 還是 18:30** 開始，使用者前後講過兩個時間），到 21:45
- 白天可以找實習；新加坡職場看重實戰經驗，不只看學歷
- Capstone 也提供這個機會，一句話帶過（其他老師會講）

**8. 心態**
- 很多人去美國英國是邊讀書邊玩；新加坡是工作導向，適合想練硬實力與軟實力、在職場拼搏賺高薪的人
- 「很多人說新加坡無聊，因為它不是拿來玩的地方，是拿來工作的地方」
- **Claude 的提醒**：主辦是 NTU CCTF，講者直接說「新加坡很無聊」有風險。建議改成引述別人的話再接自己的看法
